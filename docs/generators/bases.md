# Magnetised miniature base generator

Make replacement, conversion, and display bases for tabletop miniatures, sized exactly and hollowed underneath to hold magnets.

## Footprint

Choose a round, oval, pill, rectangle, or regular polygon base, then pick a standard size or type exact dimensions. Presets cover common Games Workshop, The Old World, Kings of War, and historical sizes, and custom footprints from 15–180mm work too. Hex bases are measured across their corners, so they drop into the space of the matching round.

## Size label

The base's size is embossed inside, so a loose print still tells you what it is: a `28.5` base says `28.5`, not `29`. Type your own label instead, such as a unit name or squad number; text that cannot fit the base is reported rather than dropped, and the filename still names the size.

## Magnets

Set the diameter, thickness, fit clearance, and depth clearance of the magnets you have. Each magnet sits flush with the face that meets a magnetised tray, and the depth clearance leaves room for adhesive behind it. The magnet count is recommended from the footprint and the magnet's size, or set it yourself for each footprint. Pockets follow a balanced arrangement or a five-pocket cross. Bases share their magnet settings with holders, movement trays, and spray trays, so every magnetised part lands on the same pattern.

## Underside

The underside is hollow, with supports that run out to every magnet pocket so each pocket prints as one connected feature. Adjust the bottom edge, wall thickness, top thickness, and the number and size of supports to suit your printer. The base prints with the face the model is glued to on the build plate, so every overhang points up and nothing needs supports.

## Batch export

Rebasing an army usually means several sizes at once. Add the current size to the batch as often as you need it, adjust each quantity, and download them together: STLs arrive as one archive with one file per size and its quantity in the name, while a 3MF keeps one object per size and lays out every copy across as many build plates as it needs. Every size in a batch shares the current base settings and follows its own magnet count. The batch is saved with your other settings.
