# Flying stem generator

Print flying stems to lift a miniature off its base.

Pick a 15, 20, 30, or 35mm stem and set the body diameter. The top joins the model with a peg, whose diameter and length you set to match the hole drilled in the miniature, or with a ball joint, whose diameter you set so the model can be posed. Each stem prints upright from its flat foot without supports, and the foot is glued directly to the base.
